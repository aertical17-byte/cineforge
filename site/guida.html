Step-by-step guide

From zero to your first image

This guide is written for people who have never installed anything technical. Follow the steps in order: if anything goes wrong, there's a “Common problems” section at the bottom.

1 · Requirements

✅ macOS 13 or later (Apple Silicon or Intel)

✅ Docker Desktop — free, the only extra thing to install: it runs CineForge on your Mac. The app opens it for you if it finds it, and takes you to the download page if it's missing.

✅ ~6 GB of free disk space (AI images are heavy)

2 · Install CineForge AI

  1. Download CineForge-AI.dmg (the “Download” button on the home page).
  2. Open the file: a window opens with the app and the Applications folder.
  3. Drag “CineForge AI” onto the Applications icon.
  4. Open the app from Launchpad or Applications.

3 · If macOS says the app “cannot be opened”

It's normal and safe: the app doesn't carry Apple's paid certificate (€99/year this project doesn't spend). The code is open source and auditable by anyone.

Fix A (works on every macOS): open Terminal and paste:

xattr -dr com.apple.quarantine "/Applications/CineForge AI.app"

Fix B (graphical, after the block appears): System Settings → Privacy & Security → scroll down to “Open Anyway” → click it → Open. Once is enough.

On macOS 14 or older: right-click the app icon → Open → Open also works.

4 · First launch

  1. In the app click “Set up & start CineForge on my Mac”.
  2. Choose the folder to keep the project in (e.g. Documents) — a cineforge subfolder will be created.
  3. The app downloads the code and builds the services. The first launch takes 5–15 minutes (it downloads a lot from the internet: that's normal; later launches are fast).
  4. Watch the progress in the window: when it's ready http://localhost:3000 opens in your browser.

5 · Create your first image (free)

  1. Open localhost:3000 — you're already in: no signup (an automatic guest session) and unlimited credits — 1,000,000, never expiring.
  2. Create a project (e.g. “My short film”).
  3. Open an Image studio and pick the engine “AI Horde · community (free, no key)” — the free one, already set.
  4. Write the prompt (e.g. “a rain-wet street, neon reflections”), choose the aspect ratio and press Generate.
  5. Find the result in the Library, downloadable and reusable.
💸 Cost: zero. The community engine uses volunteers' GPUs (open project AI Horde). Sometimes you wait 30–120 seconds in a queue — that's the price of free. ~512 px images, perfect for drafts and storyboards. Video requires an optional paid engine: the app says so clearly instead of pretending.

6 · Stop, restart, update

  • Stop everything: open the app → “Stop services”.
  • Restart: “Set up & start” (fast after the first time).
  • Update to the latest version: in Terminal: cd ~/Documents/cineforge && git pull then “Set up & start”.

7 · Common problems

❌ “Docker didn't start” — open Docker Desktop (the 🐳 whale in the menu bar), wait for the indicator to turn green, then try again from the app.

❌ “Startup failed” — check you have ~6 GB free on disk and Docker is running; technical details are in the app window. Then try again.

❌ “localhost:3000 doesn't respond after 20 minutes” — the build may still be running in the background: wait a few minutes and click “Open the app in your browser”.

❌ “Port already in use” — another app is using port 3000 or 8000: close it, or run docker compose down in Terminal and try again.

❌ I want to start from scratch — in the folder you picked: delete the cineforge subfolder, then run “Set up & start” again (Docker services reset with “Stop services”).
