# API SPECIFICATION

Base URL `/v1` unless noted. Auth: `Authorization: Bearer <jwt>`; programmatic access also accepts `X-API-Key`.
Errors: `{"detail": string | []}`; 402 = credits/plan, 401/403 auth, 422 validation, 415 unsafe upload, 429 rate-limited, 0 = network.

## OpenAPI
`/openapi.json` · interactive docs at `/api-docs` (FastAPI autogenerated from typed routes).

## Endpoints

| Method & path | Purpose | Notes |
| --- | --- | --- |
| POST `/v1/auth/register` | create account (strong password policy) | grants welcome credits; admin via ADMIN_EMAILS |
| POST `/v1/auth/login` | JWT | rate-limited per IP |
| POST `/v1/auth/forgot-password` | request reset | explicit "SMTP not configured" honest response |
| GET `/v1/auth/me` | current user | |

| GET/POST `/v1/projects`; GET/PATCH/DELETE `/v1/projects/{id}` | project CRUD | soft delete; ownership enforced |

| POST `/v1/assets/{id}/like`, DELETE `/v1/assets/{id}` | toggle like / soft delete | |
| GET `/files/{key}?token=` | signed local file serving (storage=local mode) | HMAC TTL token |
| POST `/v1/generations/preview-cost` | deterministic credit estimate | no side effects |

| GET `/v1/generations/{id}` | detail incl. assets | polled by UI |
| POST `/v1/generations/{id}/cancel` | cancel (+auto refund) | provider cancel when available |
| POST `/v1/generations/{id}/reroll` | re-run with identical settings | new generation |
| GET `/v1/credits/summary` | balance + lots | |
| GET `/v1/credits/history` | lot ledger trail | |
| GET `/v1/usage` | usage_log trail (usage history page) | |
| GET `/v1/plans` | plan catalog (admin-configured) | |
| GET `/v1/my/subscription` | current subscription | |
| POST `/v1/billing/checkout` | Stripe checkout **or** explicit admin_nowired response | no card data ever touches us |

| GET/POST `/v1/elements`; POST `/v1/elements/{id}/photos` | characters/elements + identity training request | 20–80 photos; consent required |
| GET `/v1/models` | engine catalog + capabilities + costs | drives the UI |
| GET `/v1/providers` | provider configured-status booleans (no secrets) | |
| GET `/v1/registry/{group}` | camera_moves, palettes, lighting_presets… | from shared JSON |
| GET `/v1/templates` | curated starting points | |
| GET `/v1/notifications`, POST `/v1/notifications/read` | notifications | |
| GET `/health` (root) | liveness | used by CI + compose |

## Web/E2E conventions
- All mutating UI actions send data-testid attributes (`generate`, `model-select`, `prompt`, …) mirrored by Playwright (`apps/e2e/journey.spec.ts`).

## Rate limits
- auth: 20 req/min/IP · API: 120 req/min/token-identity (env-tunable). 429 with no body mutation.
